## Descripción

Implementar middleware de validación deroles para verificar que el usuario tiene el rol requerido (client/driver/admin).

### Backend
- Crear `backend/src/middleware/role.ts`
- Middleware `requireRole(roles: string[])` para verificar rol del usuario
- Extraer rol desde MongoDB (basado en clerkId)
- Retornar 403 si el rol no coincide

### Criterios de aceptación
- [ ] Rutas de driver solo accesibles por usuarios con rol "driver"
- [ ] Rutas de cliente solo accesibles por usuarios con rol "client"
- [ ] Middleware reusable para cualquier ruta
